Binary Format Specifications

How does Brother #PES0001 store hoop size and thread colors? ▾

A Brother .PES file begins with the 8-byte ASCII signature #PES0001 followed by a 32-bit little-endian pointer (at byte 0x08) to the PEC stitch block. At pecOffset + 48, the file stores colorCount - 1 followed by 1-byte indices into the 64-color Brother PEC thread table. Stitch coordinates follow at pecOffset + 552 in 0.1mm increments.

Why can't I convert a PNG or SVG inside this open-source inspector? ▾

pes-dst-inspector is a lightweight, zero-dependency binary parser for existing stitch files. Converting raster or vector artwork into machine embroidery requires contour tracing, underlay generation, pull-compensation math, and short-stitch corner routing—available online at ImageToPES.com.
